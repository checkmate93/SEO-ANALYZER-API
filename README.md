# Ultimate SEO & Readability Analyzer API 🚀

This API analyzes text and URLs for SEO optimization and readability.

## Endpoints
- `GET /`: Health check.
- `POST /analyze/text`: Send raw text to get SEO metrics.
- `POST /analyze/url`: Send a URL to scrape and analyze its content.

## How to use
Built with FastAPI. Documentation available at `/docs`.
